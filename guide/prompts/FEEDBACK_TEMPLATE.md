# 反馈与记忆更新模板

用户不必完整填写；Agent 可据此从自然语言反馈中提取信息。

```markdown
## 本次反馈

- 哪部分符合预期：
- 哪部分不符合预期：
- 希望如何修改：
- 可作为验收样例的结果：

## 适用范围

- [ ] 仅本次
- [ ] 当前项目
- [ ] 同类任务
- [ ] 所有未来任务

## 是否沉淀为记忆

- [ ] 不记录
- [ ] 可自动记录
- [ ] 请先给出拟写入内容让我确认
```

Agent 处理后应返回：

```markdown
本次已修正：[内容]
记忆处理：[未记录 / 已写入文件与范围 / 等待确认]
拟执行规则：[一句可操作的规则]
```
